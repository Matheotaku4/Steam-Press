Pack Steam games cleanly, fast, reliably.

Steam Press downloads Steam depots, produces clean app manifests, compresses the result and generates cs.rin.ru release notes — from a CLI or a native desktop app.

Features

Everything the packing workflow needs.

A Rust reimplementation of the SuperSteamPacker workflow, with the reliability ideas of OmniPacker.

Two download engines

SteamCMD by default or DepotDownloader, behind one abstraction. Queue games with platform, branch and protected branches, plus Workshop items.

Clean manifests

Reads .acf, sanitizes LastOwner and LauncherPath, and generates full manifests — including the redistributables one.

7-Zip & RAR archives

5 GB volumes, encrypted headers and the cs.rin.ru password by default, or your own options. Archives are verified, with sha256sum-compatible manifests.

Release notes

Built-in [CS.RIN.RU Info] and [Upload Crew Info] templates, or write your own with tokens and a per-depot loop.

Secure by design

Credentials in an AES-256-GCM encrypted vault (0600), never logged and never passed on a command line.

Resumable & safe

Disk-space preflight, checkpointed work directories, --fresh restarts, and cancellation that keeps partial archives.

Import & diff

Import a local install or compare two builds to produce an update archive, with a deleted_files.txt manifest.

Native desktop app

An egui GUI with Library, Workshop, History, Depots and Settings. Light/dark themes, Lucide icons, auto-saved queues and in-app updates.

Scriptable

Global --json output for doctor, search, info, queue, pack, diff and more. SuperSteamPacker-compatible .SSPQ / .SSWQ queues.

Pipeline

From App ID to release, in four steps.

Download

Depots and shared redistributables via SteamCMD or DepotDownloader.

Sanitize

Privacy-clean .acf files and complete app manifests.

Compress

7z or RAR volumes, verified, with SHA-256 checksums.

Publish

Ready-to-paste cs.rin.ru notes from a template.

Quick start

Up and running in a minute.

build

cargo build --release \
  -p steam-press-cli \
  -p steam-press-gui

# desktop app
cargo run -p steam-press-gui

# check your setup
steam-press doctor

usage

steam-press login
steam-press depots sync
steam-press queue add 2379780 --os lin64
steam-press pack --queue queue.sspq --compressor 7z
steam-press import /games/MyGame --appid 2379780
steam-press diff ./build-a ./build-b --archive

Requires Rust 1.88+, steamcmd and 7z in your PATH. A rar binary and DepotDownloader are optional.
